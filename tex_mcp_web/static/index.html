    Where to find the cookie
    1. Sign in to Overleaf in another tab.
    2. Open the developer tools there: Application (Chrome, Edge) or Storage (Safari, Firefox), then Cookies, then overleaf.com.
    3. Copy the value of overleaf_session2 and paste it above.

    Guides: Chrome · Edge · Firefox · Safari

    The value signs in as you. It is kept in your own config folder and is not shown here again.
