    Where to find the cookie

    Sign in to Overleaf and open the browser's developer tools: Application (Chrome, Edge) or Storage (Safari, Firefox), then Cookies, then overleaf.com. Copy the value of overleaf_session2. Anyone with this value can sign in as you, so it is stored in your own config folder, readable only by you, and is not shown here again.
