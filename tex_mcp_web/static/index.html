    Where to find the cookie

    On Overleaf, signed in, open the browser's developer tools: Application (Chrome, Edge) or Storage (Safari, Firefox), then Cookies, then overleaf.com. Copy the value of overleaf_session2. It signs in as you, so it is kept in your own config folder, readable by you alone, and is not shown here again.
