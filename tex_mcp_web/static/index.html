            Help

            Add a comment

            Select words in the Preview and choose Comment. In the Source, select text and press the comment button in the editor's toolbar. For a figure, a table or anything else without text to select, choose the box tool in the Preview's toolbar and draw a box over it. To comment on the paper as a whole, choose Comment on the whole paper… in the ⋯ menu.

            Call the agent

            Write as many comments as you like. When they are ready, press the bell above the comment list, or Ctrl+Alt+Enter, and the agent receives them all at once. The bell is green while an agent is listening. When it is red, the call is queued until an agent connects.

            Read the reply

            The agent edits the LaTeX source, compiles the paper and replies in each comment's thread. When the wording is yours to decide, it proposes a change instead. The card shows the current lines marked − and the new ones marked +, and the Source highlights the same text in red. Apply suggestion writes the change into the file, and Reject discards it. To ask for something different, use Reply privately and call the agent again.

            A comment is unanswered when its last message is from the agent. Its card is marked unanswered, the unanswered view lists only those comments, and the number on the Comments tab counts them.

            Finish a thread

            When the change is what you wanted, press Resolve on the card. Archive sets a thread aside without resolving it, and you can still reply to it. After either one, a line above the list says what was done, and Undo on that line, or the u key, reverses it.

            The search box above the comment list finds comments in the tab that is open, in any status. Press / to go to it.

            Example: a co-author's comment

            Suppose several people work on the paper on Overleaf, and you want to find a comment your co-author Ann Lee left a few days ago. You remember that it was about 2_main.tex and that she wrote it on the morning of November 13. Open the Comments tab, where the threads from Overleaf are listed, and type the following in the search box.

            1. from:ann

              The list shows only the threads Ann Lee wrote in, on any file. As you type after from:, the names of the people in the tab appear under the box, and you can pick one with a click or with the arrow keys and Enter.

            2. from:ann file:2_main

              Adding file:2_main leaves only her threads on 2_main.tex. Part of a file name is enough.

            3. from:ann file:2_main after:11-12 before:11-14

              after:11-12 keeps the threads with a message written on or after November 12, and before:11-14 keeps those with a message written before November 14. Two threads are left.

            4. from:ann file:2_main after:11-13T09 before:11-13T12

              A time works the same way, here 9:00 and 12:00 on November 13. Only the comment you were looking for is left.

            While you search, the view list shows all, because the search covers threads in every status. Press Enter to move to the results and go through them with the keys. Press Escape in the search box to clear the search and return to the view you had.

            The sort list orders the results as it does in any view. With paper order, threads from Overleaf follow the order of the paper, and your own comments the order you wrote them in. latest first and oldest first order them by each thread's most recent message.

            Search terms

            SearchFinds threads that
            caption widthcontain both words, in any order
            figure OR tablecontain either word
            "base case"contain the exact phrase
            -appendixdon't contain the word
            from:annhave a message from someone whose name contains “ann”
            file:2_mainare on a file whose path contains “2_main”
            after:11-12have a message written on or after November 12
            before:11-14have a message written before November 14

            Write OR in capitals. It splits the search into alternatives, so caption width OR table finds threads that contain both caption and width, or that contain table. A minus also works before a phrase or a term with a colon, as in -from:agent. Use from:me for your own messages, from:agent for the agent's, and quotes for a name with a space, as in from:"Ann Lee".

            Dates and times

            DateMeans
            11-12November 12 of this year
            2026-11-12November 12, 2026
            11-12T099:00 on November 12
            11-12T09:309:30 on November 12
            "11-12 09:30"9:30 on November 12, written as the comment cards show it

            Dates and times are in your computer's time zone, as on the comment cards. A date without a time means the start of that day, so before:11-14 still includes November 13.

            The search looks for words in the messages and their writers' names, the text a comment is on, its file name, proposed changes and drafts for Overleaf. Capital letters don't matter. Each term is checked against the whole thread rather than a single message, so from:ann after:11-12 also finds a thread Ann Lee wrote in on November 10 if someone else replied on November 12. A word with a colon that isn't one of these terms, such as note:, is searched for as an ordinary word.

            Once the paper is connected to its Overleaf project in Settings, the comment threads from Overleaf appear in a second Comments tab, marked with a leaf . The first Comments tab lists the comments you write for the agent.

            Views in the leaf tab

            The leaf tab opens on open, which lists its open threads and, after them, the suggested edits waiting for you to accept or reject. A thread is unanswered when its last message on Overleaf is from someone else, and the unanswered view lists only those threads. The number on the tab counts the unanswered threads and the suggested edits. The drafts view lists the threads with something not yet sent to Overleaf, new threads first and then replies the agent has drafted.

            Public and private messages

            Comments in the first Comments tab are private, so only you and the agent can see them. A thread from Overleaf can contain both kinds of message. Your co-authors' messages and the replies you send are public, marked public, and everyone in the project can read them. Messages you exchange with the agent through Reply privately are marked private and are never sent to Overleaf.

            Replying on Overleaf

            The box under a thread is for its public reply. The agent can write a draft there for you to edit. Send to posts the reply to Overleaf, where everyone in the project can read it. To send the replies of several threads at once, select them and press the send button above the list. Reject draft removes the agent's draft. Say why in a private reply, and the agent will write a new one the next time you call it.

            To start a new thread on Overleaf, turn on the leaf in the Source toolbar, then select text in the Source and comment on it.

            Resolving and hiding threads

            Resolve and Reopen on a thread from Overleaf change it on Overleaf, for everyone in the project. When you resolve or reopen several selected Overleaf threads at once, the page asks you to confirm first. Undo reverses the change on Overleaf too.

            Overleaf has no archive. To put a thread out of the way without changing it on Overleaf, press Hide. It stays open for everyone else and moves to the hidden view, where Show brings it back. If someone else writes in a hidden thread, it is shown again so that you don't miss the message.

            Your co-authors and your cursor

            Co-authors who have the project open appear as faces in the top bar. Click a face to go to the file and line that person is on. In Settings, under Your cursor on Overleaf, Show my cursor lets your co-authors see your cursor in this page's editor, and you see theirs as they move. With Hidden, they don't see your cursor, and Overleaf doesn't show you as online. You can still see who is in the project, but their cursors may be up to five minutes old.

            git pull and commit & push

            If the paper's folder is a git clone of the Overleaf project, git pull and commit & push appear in the top bar when there is something to pull or push. The number on git pull is how many commits Overleaf has that this folder doesn't, and the number on commit & push is how many commits it will send. In a folder that isn't a git clone, the buttons read Get and Send and count files instead.

            With Vim keys

            To use Vim keys, turn them on in the ⋯ menu at the end of the editor's toolbar. These keys then work along with Vim's usual ones.

            :wSave the file :makeCompile the paper jjEscapeCtrl+[Leave Insert mode. Type jj quickly. gcComment on the text a motion or selection covers, as in gcc for the line or gcip for the paragraph gsShow the text a motion or selection covers in the Preview, as in gss for the line KGo to the comment at the cursor in the comment list gdCtrl+]Go to the file, label or .bib entry named at the cursor Ctrl+OCtrl+TGo back. On Windows, use Ctrl+O, since the browser opens a new tab with Ctrl+T.
